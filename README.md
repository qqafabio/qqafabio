<h1 style="color: white; font-family: 'Fira Code Retina',serif">Olá, meu nome é Fábio Morais</h1>

<p style="color: white; font-family: 'Fira Code Retina'">Sou Analista de Qualidade de Software (QA) e apaixonado pela área. Trabalho com metodologia ágil (scrum), sou atento a detalhes para testes e documentações, capacidade analítica para definir qual o tipo de teste ideal a ser utilizado, resiliência, proatividade e organização.
